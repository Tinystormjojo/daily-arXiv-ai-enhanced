### [2] [Quotient DAGs for Off-Policy Evaluation:Forward-Flow Importance Sampling and Exact Slate Propensities](https://arxiv.org/abs/2605.29500)
*Ziwen Xie,Shaowen Xiang,Hongyu He,Dianbo Liu*

Main category: cs.LG

TL;DR: This paper proposes a quotient DAG-based approach for off-policy evaluation of slate recommendation, which computes exact unordered slate propensities efficiently without factorial enumeration, enabling practical propensity-based policy evaluation and model selection.

Motivation: Standard importance sampling for off-policy evaluation introduces nuisance variance and computational bottlenecks, because it treats irrelevant generation process details (like ordered generation sequences for unordered slates in recommendation) as meaningful. Exact calculation of unordered slate propensities requires summing over all generation orders, which is computationally infeasible.

Method: A quotient-DAG view is introduced that merges histories that are equivalent for evaluation, and assigns weights using target-to-behavior forward-flow ratios on the merged graph. For slate recommendation with set-sufficient next-item interface, a dynamic programming method called Forward-DP is derived on a subset DAG to compute exact unordered propensities without factorial enumeration of all generation orders.

Result: The proposed method enables efficient calculation of exact unordered slate propensities for context-dependent autoregressive slate loggers, supporting practical propensity-based off-policy evaluation and model selection that was previously computationally intractable.

Conclusion: The quotient-DAG framework effectively reduces nuisance variance and solves the computational gap of exact unordered slate propensity calculation, enabling practical off-policy evaluation for autoregressive slate recommendation systems.

Abstract: Off-policy evaluation estimates how a target policy would perform using data collected by a different behavior policy, which is crucial when online testing is costly or risky, such as in recommendation or healthcare. Standard importance sampling reweights each logged trajectory, but it can treat details of the generation process as meaningful even when the evaluation target ignores them: for example, an autoregressive slate recommender may generate an ordered sequence of items while the reward and downstream estimator depend only on the unordered slate. This creates nuisance variance and a computational gap, since exact unordered slate propensities require summing over all generation orders. We introduce a quotient-DAG view that merges histories equivalent for evaluation and assigns weights using target-to-behavior forward-flow ratios on the merged graph. For slate recommendation under a set-sufficient next-item interface, this yields Forward-DP, a subset-DAG dynamic program that computes exact unordered propensities without factorial enumeration. The resulting propensity primitive enables practical propensity-based evaluation and model selection for context-dependent autoregressive slate loggers.
