### [1] [When LLM-Based User Profiling Adds Value in Production Streaming Recommendation](https://arxiv.org/abs/2609.27183)
*Milad Sabouri,Neeraj Sharma,Sardar Hamidian,Shaghayegh Agah*

Main category: cs.IR

TL;DR: This paper systematically compares four combinations of semantic user profiling paradigms (aggregate vs LLM-based) and temporal handling (with/without temporal disentanglement) on a real-world production streaming recommendation dataset, answering when the more expensive LLM-based user profiling brings additional value.


<details>
  <summary>Details</summary>
Motivation: LLM-based user profiling for content recommendation is much more computationally expensive than traditional aggregate methods, but it remains unclear when the extra cost is justified, and there is a lack of systematic comparison of these strategies across different settings and evaluation dimensions.

Method: The authors designed a factorial experiment crossing two representation types (aggregate of item embeddings vs LLM-generated natural language preference summaries encoded by text encoder) and two temporal handling strategies (with vs without temporal disentanglement of recent/historical behavior), resulting in four strategies, which were evaluated on a real-world production dataset across different user behavior types and temporal window settings, covering both accuracy and beyond-accuracy metrics.

Result: The comparison reveals differences among the four strategies in recommendation quality (both accuracy and beyond-accuracy metrics) across different user behavior types and temporal disentanglement window settings, characterizing when LLM-based profiling adds value relative to cheaper aggregate methods.

Conclusion: The value of LLM-based user profiling in production streaming recommendation varies depending on user behavior type and temporal window setting for disentanglement, providing guidance for practitioners to choose when to adopt the more expensive LLM-based approach.

Abstract: Personalized recommendation depends critically on how user representations are constructed from historical behavior. Two paradigms have emerged for constructing semantic user profiles in content-based recommendation. First, aggregate methods derive user representations as numerical aggregates of semantic item embeddings. Second, LLM-based methods generate natural-language summaries of user preferences and encode them through a text encoder. Each paradigm can be combined with temporal disentanglement of recent versus historical behavior. LLM-based profile generation is significantly more expensive than aggregate approaches, raising the question of when this additional cost is justified. We present a systematic comparison of four semantic user-profiling strategies, factorially crossed across representation type and temporal handling, evaluated on a real-world production dataset. The comparison reveals how these strategies differ across user behavior types, across both accuracy and beyond-accuracy dimensions of recommendation quality, and across the temporal-window setting that governs the disentanglement.
