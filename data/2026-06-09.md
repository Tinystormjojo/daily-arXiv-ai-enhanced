### [1] [Generative Archetype-Grounded Item Representations for Sequential Recommendation](https://arxiv.org/abs/2606.11023)
*Yifan Li,Jiahong Liu,Xinni Zhang,Hao Chen,Yankai Chen,Wenhao Yu,Jianting Chen,Irwin King*

Main category: cs.IR

TL;DR: 本文提出了一种用于序列推荐的生成式原型 grounded 物品表示框架GenAIR，通过LLM推断物品目标受众原型并结合行为校准优化物品表示，提升多个序列推荐模型的性能，效果超过现有最优基线。


<details>
  <summary>Details</summary>
Motivation: 序列推荐中物品表示质量不足是关键瓶颈，现有基于LLM的方法仅利用物品固定属性做静态编码，忽略了目标受众对物品身份定义的关键作用，且语义空间难以匹配实际用户行为，语义表示和行为模式之间存在显著差距。

Method: 提出GenAIR通用框架：1）利用LLM分析物品元数据，推断代表物品理想目标受众概念画像的原型文本描述，单前向传播提取对应嵌入；2）引入行为校准目标，显式融入实际交互的行为信号，调整嵌入空间结构以匹配经验行为模式，该框架可无缝集成到多数现有序列推荐模型中，保持高效性。

Result: 在三个真实世界数据集上的综合实验表明，GenAIR显著提升了多种序列推荐模型的性能， consistently 优于现有最优基线方法。

Conclusion: GenAIR是一种有效的增强序列推荐物品表示的框架，可兼容多数现有模型，在保持高效率的同时显著提升推荐性能，优于当前SOTA方法。

Abstract: Sequential recommendation aims to predict users' next interaction with items by analyzing their historical behavior. However, the limited quality of item representations remains a critical bottleneck. While pre-trained large language models (LLMs) can provide rich semantic representations, existing approaches only rely on static encoding of fixed attributes, overlooking the crucial role of target audiences in defining item identity. Moreover, the semantic space struggles to reflect actual user behavior, resulting in a significant gap between semantic representations and behavioral patterns. To address these limitations, we propose GenAIR, a general framework that empowers sequential recommendation with Generative Archetype-grounded Item Representations. Specifically, we first leverage an LLM to analyze item metadata and infer textual description of the Archetype, which represents the conceptual profile of the item's ideal target audience. We then extract the corresponding embeddings in a single forward pass. Further, to ground these generative archetypes in real-world behavior, we introduce a behavioral calibration objective, which explicitly incorporates behavioral signals from actual interactions. This objective adjusts the structure of the embedding space to reflect empirical patterns. GenAIR enables seamless integration with most existing models while maintaining high efficiency. Comprehensive experiments conducted on three real-world datasets demonstrate that GenAIR significantly improves the performance of various sequential recommendation models and consistently outperforms state-of-the-art baseline approaches. Implementation codes are available at https://github.com/AI-Santiago/GenAIR.

### [2] [SIDInspector: A Mapping-First Diagnostic Resource for Semantic-ID Tokenizers](https://arxiv.org/abs/2606.10375)
*Jiandong Ding,Heng Chang,Huijie Qin,Tianying Liu*

Main category: cs.IR

TL;DR: This paper introduces SIDInspector, a mapping-first diagnostic tool for Semantic-ID (SID) tokenizers that are widely used as standalone artifacts in generative recommendation. SIDInspector defines an adapter contract for SID mappings and related data, runs multiple mapping-level diagnostics, and reports issues before downstream model training. Experiments on multiple public SID tokenizer artifacts reveal new findings about aliasing, prefix alignment and addressability of SID mappings.


<details>
  <summary>Details</summary>
Motivation: SID tokenizers are increasingly reused as standalone artifacts in generative recommendation, but there is no common inspection interface for their exported item-to-code mappings. Common problems such as coverage gaps, full-code aliasing, weak prefixes, tail compression and prefix fan-out are often only discovered after downstream model training, which wastes development and computation resources.

Method: SIDInspector adopts a mapping-first diagnostic framework. It first defines a small adapter contract that unifies the interface for item mappings, metadata, user interactions and optional generator traces. Then it validates the contract and runs multiple mapping-level probes to evaluate utilization, aliasing, neighborhood alignment, popularity allocation, structural cost, and supports extensions for temporal churn and generator trace analysis.

Result: Diagnostic results on 4 types of SID tokenizer artifacts over 23,742 musical items show that: GRID-style tokenizer has a 0.977 full-code aliasing rate, while ReSID/GAOQ's exported mapping is aliasing-free. The best prefix co-occurrence alignment comes from deterministic category-prefix mapping (0.447), which outperforms both learned methods (0.154 and 0.055-0.080). Cross-domain experiments confirm that prefix alignment is an independent candidate-exposure signal, while final ranking performance depends on downstream models.

Conclusion: SIDInspector is an effective open diagnostic resource for SID tokenizer artifacts, which can detect mapping-level issues before downstream training. Diagnostics show that addressability and behaviorally meaningful prefixes of SID mappings should be inspected separately, and prefix alignment can serve as an independent diagnostic signal for candidate exposure.

Abstract: Semantic-ID (\sid) tokenizers are increasingly reused as standalone artifacts in generative recommendation: an exported item-to-code mapping becomes the address space that a later sequence generator must use. These mappings rarely come with a common inspection interface, so coverage gaps, full-code aliasing, behaviorally weak prefixes, tail compression, and prefix fan-out are often found only after downstream training. We present \tool, a mapping-first diagnostic resource for \sid tokenizer artifacts. \tool defines a small adapter contract over item mappings, metadata, interactions, and optional generator traces; validates the contract; and reports mapping-level probes for utilization, aliasing, neighborhood alignment, popularity allocation, and structural cost, with hooks for temporal churn and generator traces.
  \tool reports inspectable artifact profiles before downstream leaderboard scores. The released resource covers four tokenizer artifact lines: a same-item GRID/RQ-KMeans-style and ReSID/GAOQ contrast on 23,742 Musical items, plus released LETTER and LC-Rec item-index artifacts. In the Musical contrast, the GRID-style feature-text export has 3,749 unique full codes and a 0.977 full-code aliasing rate, while ReSID/GAOQ is aliasing-free in its exported mapping. Yet the strongest prefix--co-occurrence alignment comes from a deterministic category-prefix control, not from either learned export row (0.447 versus 0.154 and 0.055--0.080), showing that addressability and behaviorally meaningful prefixes should be inspected separately. Cross-domain, fixed-reranker, and mechanism-probe checks support the same diagnostic direction: prefix alignment is a candidate-exposure signal, while final ranking quality remains a downstream model question.
